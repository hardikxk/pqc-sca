\begin{abstract}
We present MojoPQC-SCA, a reproducible pipeline for evaluating lightweight deep-learning models on masked ML-KEM-style side-channel traces. The system combines bounded-memory HDF5 processing, a compact one-dimensional convolutional baseline, and a Matrix Product State classifier head. Training can be performed in a cloud notebook, while preprocessing, inference, and evaluation remain suitable for CPU-only environments. Results in this scaffold must be replaced with measurements from the saved experiment artifacts before submission.
\end{abstract}

\section{Introduction}
Post-quantum cryptographic implementations require side-channel evaluation under realistic masking and measurement conditions. This work focuses on an engineering question: can compact models and efficient preprocessing provide a reproducible baseline under constrained compute?

\section{Method}
Raw traces are normalized per trace, smoothed with an odd-length moving-average FIR filter, aligned to a reference using bounded cross-correlation, and reduced to at most 5,000 samples. The CNN contains two convolutional blocks with 16 and 32 channels. The CNN+MPS variant contracts learned bond-dimension-8 cores before classification. All model sizes are checked programmatically.

\section{Evaluation protocol}
Profiling and attack partitions are generated with independent labels and deterministic seeds. Guessing entropy is computed from cumulative log-probability evidence, and preprocessing experiments report elapsed time, throughput, and speedup. Hardware traces should be reported separately from synthetic traces and should include sampling rate, device, masking implementation, and acquisition conditions.

\section{Reproducibility}
The repository fixes configuration in YAML, stores benchmark data as JSON and CSV, and provides a Colab notebook. The exact command sequence and external-data contract are documented in `RUN_AND_DEMO.md`.

\section{Limitations and future work}
The current synthetic generator is not a substitute for a hardware acquisition study. Native Mojo kernels, Numba acceleration, ONNX calibration, and comparison figures require additional validation and should be clearly labeled as such.
